# Changelog entries

Every entry goes under `## [Unreleased]`, grouped by a heading: `### Added`, `### Fixed`, or `### Changed`.

Entry format, one line each:
- Added:   `- ✨ <what was added> (by @omkar)`
- Fixed:   `- 🔧 <what was fixed> (by @omkar)`
- Changed: `- ♻️ <what changed> (by @omkar)`

Rules:
- Start with the emoji for the group. End with `(by @omkar)`.
- Write in past tense, under 100 characters.
- Describe the effect on the user, not the code change.
