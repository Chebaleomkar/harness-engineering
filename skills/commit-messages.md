# Commit messages

Format: `<type>(<scope>): <summary>` where type is one of feat, fix, docs, refactor, test, chore.

Rules:
- Summary is imperative, lowercase, no trailing period, under 60 characters.
- Add a body only when the reason is not obvious from the summary.
- Never mention an AI tool in the message.
- Reference an issue as `Refs #123` on the last line.
