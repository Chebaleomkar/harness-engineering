# Bug reports

Use exactly these sections, in order:
1. **Summary**: one sentence.
2. **Steps to reproduce**: a numbered list a stranger can follow.
3. **Expected**: what should happen.
4. **Actual**: what happens, with the exact error text.
5. **Environment**: OS, Node version, and commit hash.

Rules:
- Label it `bug`. Add `regression` if it worked in an earlier version.
- One bug per report.
- Do not guess the cause in the report. Put guesses in a comment.
